What makes a redesign different from a new website build?

A new website starts with a blank architecture. A redesign inherits decisions that already exist: URLs, content, analytics, CMS data, integrations, templates, forms, conversion tracking, and sometimes years of search visibility. Reusing good parts can save money, but preserving or untangling old systems also creates migration work that a new build does not have.

  • Design-only refresh: keep the content model and platform, replace visual styles and templates.
  • Structural redesign: reorganize navigation, templates, page types, and content while retaining the same underlying platform.
  • Replatform: move to a different CMS or framework and migrate content, forms, data, and integrations.
  • Commerce redesign: add product, customer, order, payment, and tracking migrations to the normal redesign workload.

SEO and migration work that belongs in the budget

When redesign work changes URLs or site structure, SEO preservation becomes part of implementation rather than a separate cosmetic task. A migration plan should inventory important URLs, decide which URLs remain unchanged, map changed URLs to relevant destinations, carry over indexable content and metadata, and test redirects and canonicals before launch.

Google's site-move guidance recommends preparing URL mappings and thoroughly testing the new site when URLs change. Performance work can also be part of redesign scope; Google's Web Vitals guidance explains the user-experience metrics commonly monitored during a rebuild.

That is why this calculator treats a large URL/architecture migration as a separate cost driver. It represents planning, implementation, validation, and launch risk—not a guarantee that rankings will stay unchanged.

Website redesign quote checklist

Before comparing redesign quotes, make sure each provider is pricing the same work. A low quote can simply exclude migration or content tasks that another proposal includes.

  • Number of unique page templates and approximate page count.
  • What content is reused, edited, rewritten, or migrated.
  • CMS/platform migration and data export/import responsibilities.
  • Forms, CRM, booking, payments, analytics, and other integrations.
  • Redirect mapping, canonical validation, metadata transfer, and launch QA.
  • Accessibility, responsive testing, browser/device testing, and performance work.
  • Revision rounds, stakeholder approvals, training, documentation, and post-launch support.

Website Redesign Cost Calculator: common questions

How much does a website redesign cost?

Website redesign cost depends on how much of the existing site can be reused. A visual refresh on the same platform is usually less work than a rebuild that changes the CMS, migrates content, preserves SEO signals, and replaces custom functionality. Use the calculator above to model those differences.

Is a redesign cheaper than building a new website?

Often, but not always. Reusing a stable CMS, content, and integrations can reduce work. If the old site has technical debt, outdated templates, difficult migrations, or major SEO requirements, a redesign can approach the cost of a new build.

What should an SEO-safe redesign include?

An SEO-aware redesign should preserve valuable URLs where possible, map any changed URLs to permanent redirects, carry over important metadata and structured content, and validate the new site before launch. Large structural changes should be planned as a migration, not just a visual refresh.

Does this calculator include copywriting and content migration?

The content-work input lets you model reuse, light editing, or substantial rewrite/migration effort. It is a planning allowance, not a quote for a specific copywriting or migration scope.
